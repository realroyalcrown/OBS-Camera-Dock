# Windows 0.4.3 preview — Razer Kiyo V2 X

Základní ovládání Razer Kiyo V2 X na Windows je funkční a ověřené uživatelem.

- Ovládání parametrů kamery, presety a panel pro OBS.
- Vlastní ikona, odkaz realroyalcrown.eu, verze a kontrola aktualizací v nabídce lišty.
- Logitech C920 a ostatní UVC kamery vyžadují další ověření a doladění.
- Expozice podle obličeje, ostření podle obličeje a digitální tracking jsou experimentální a vyžadují doladění.

Windows 10/11 x64. Rozbalte Windows ZIP a spusťte OBS Camera Dock.exe. Před aktualizací ukončete předchozí helper. Nastavení zůstává zachované.

Sestavení a softwarové testy prošly. Toto je předběžné Windows vydání, nikoliv potvrzení funkčnosti všech kamer a automatických funkcí.
